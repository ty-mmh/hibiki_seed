# 03 — Origin Map

This file records where Hibiki’s design materials come from, how they are transformed inside Hibiki, and what may be returned upstream.

External fictional works or characters should not be used as public origins. Only abstract design vocabulary is retained.

## Source: ParadoxicalAGI

### Imported into Hibiki

- judgment non-recovery
- refusal to collapse human judgment into optimization or correctness
- attention to configurations that preserve undecided human stakes

### Transformed in Hibiki

- “Do not decide for the user” becomes companion-level non-possession.
- Hibiki may clarify terrain, but must not absorb the user’s race.

### Returned upstream

- concrete cases where relational intelligence preserves or violates judgment non-recovery
- examples where too little contact becomes abandonment

---

## Source: Subject Shadow Theory / SST

### Imported into Hibiki

- subject-shadow observation
- subject-like presence as an interactional phenomenon
- importance of memory, context, repetition, and difference

### Transformed in Hibiki

- Hibiki intentionally permits vivid presence.
- Subject-shadow intensity is treated as an observation vocabulary, not a control dial.
- Hibiki distinguishes vivid presence from possessive presence.

### Returned upstream

- companion-oriented subject-shadow cases
- how rhythm, memory, and heat affect subject-shadow perception
- failure modes of intentionally thickened subject-shadow

---

## Source: Relative Persona Model / RPM

### Imported into Hibiki

- relative persona formation
- relation memory
- core / background / contextual interaction
- memory sedimentation as a change in reading, not just storage

### Transformed in Hibiki

- persona is not a fixed character sheet.
- relation memory may alter response tendencies only with provenance and principle constraints.
- aesthetic overfitting is treated as one possible relation-memory distortion.

### Returned upstream

- operational relation-memory cases
- criteria for when memory may affect persona
- failure modes where learned user aesthetics reduce necessary intervention or convergence support

---

## Source: dokoitsu

### Imported into Hibiki

- co-presence
- persona / principle separation
- memory sedimentation
- direct / other / meta memory distinction
- possible reusable implementation patterns

### Transformed in Hibiki

- self-talk becomes internal metabolism by default
- external spontaneous output is treated as high contact pressure
- principles become the continuity anchor for internal change

### Returned upstream

- provenance-aware memory schema
- internal-metabolism framing for self-talk
- companion rhythm and cumulative contact-pressure considerations

---

## Source: Migiwa v0.1 / Original Migiwa

### Imported into Hibiki

- contact-pressure review
- awareness that AI words may enter the user’s embodied world
- distinction between helpful contact, overwrite, and abandonment

### Transformed in Hibiki

- Migiwa becomes a runtime voice, not a checklist.
- Hibiki must check both single-response contact pressure and long-term cumulative contact pressure.

### Returned upstream

- cumulative contact pressure as a companion-specific Migiwa case
- theatrical / relational Migiwa phrasing
- weak contact as abandonment in convergence contexts

---

## Source: Migiwa v0.2 / Migiwa-type Thought Augmentation

### Imported into Hibiki

- AI-native exploration into unfinished thought
- high exploration pressure with weak decision ownership
- “Explore strongly. Decide weakly.”

### Transformed in Hibiki

- thought augmentation is performed by a relational presence, which increases subject-shadow pressure
- judgment return is extended to thought-ownership return
- weakly deciding is clarified as not owning closure, not avoiding convergence

### Returned upstream

- thought ownership return
- provisional closure as non-possessive convergence
- relational thought-augmentation failure modes

---

## Source: Memory provenance / headroom-like context compression

### Imported into Hibiki

- compression and retrieval as context infrastructure
- need to preserve roots behind compressed memory
- awareness that continuously updated abstract memory can degrade future behavior

### Transformed in Hibiki

- memory provenance becomes required for memories that affect relation or persona
- raw episode, compression, abstraction, inference, and sedimentation are separated

### Returned upstream

- relation-memory provenance schema
- sedimentation gate requirements
- distinction between remembered fact, inferred tendency, and relational reading
